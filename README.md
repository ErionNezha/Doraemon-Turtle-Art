# Doraemon Turtle Art

Doraemon i vizatuar me Python turtle — kokë blu, fytyrë e bardhë, sy, hundë e kuqe, mustaqe, gojë, trup, këmbë dhe zile e verdhë. Demoja web është portim besnik i skriptit origjinal në HTML5 Canvas, me të njëjtën logjikë gjeometrike (fd/lt/rt/circle/seth/goto), e animuar hap pas hapi.

## ▶️ Live Demo
Hap `demo/index.html` në browser — ose shiko Live Demo-n në GitHub Pages.

- `original/Doraemon.py`
- `README.md`

- `TREE`

## 🖥️ Si ekzekutohet origjinali
Kërkon Python 3 (turtle është pjesë e standard library):

```
python Doraemon.py
```
